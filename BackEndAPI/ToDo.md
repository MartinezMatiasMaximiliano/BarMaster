# Auth
- [ ] Loguear a nivel Empresa <br>
Crea un token JWT para una empresa específica, permitiendo el acceso a TODA la info de la empresa.

- [ ] Loguear a nivel Sucursal <br>
Crea un token JWT para una sucursal específica dentro de una empresa, permitiendo acceso al front UNICAMENTE de la sucursal.

- [ ] Loguear a nivel Persona <br>
Crea un token JWT para una persona específica dentro de una sucursal, permitiendo acceso al front de administracion de la sucursal.
